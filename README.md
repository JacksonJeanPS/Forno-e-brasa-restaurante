# Forno & Brasa Restaurante

Site editorial para um restaurante brasileiro fictício, com cardápio interativo e prévia de pedido.

## Demonstração

[Acessar projeto na Vercel](https://forno-e-brasa-restaurante.vercel.app/)

## Funcionalidades

- Cardápio separado por categorias
- Carrinho com adição, remoção e cálculo do total
- Envio da prévia do pedido pelo WhatsApp
- Informações de funcionamento e reservas
- Experiência responsiva e otimizada para compartilhamento

## Tecnologias

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4

## Executar localmente

```bash
npm install
npm run dev
```

Acesse `http://localhost:3000`.

## Aviso

Projeto demonstrativo. Restaurante, cardápio, preços, endereço e contatos são fictícios.
